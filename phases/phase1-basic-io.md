# Phase 1: Basic I/O（基本操作）

## 到達状態

> AI に「調べて」「書いて」「整理して」と指示し、結果をファイルとして受け取れる。
> 「自分でやるより AI にやらせた方が速い」という感覚を得ている。

## この Phase で学ぶこと

- Cursor の基本操作（チャット、インライン編集、エージェント）
- Claude Code の基本操作（自然言語での指示、ファイル操作）
- AI への効果的な指示の出し方（基礎）

## 1-1. Cursor の基本操作

### Chat（Cmd+L）— AI に質問・相談する

**何ができるか**: サイドパネルで AI とチャット形式で対話する。質問、相談、分析依頼に使う。

**使い方:**
1. `Cmd+L` でチャットパネルを開く
2. 質問やリクエストを入力
3. `@` でファイルやフォルダを参照に追加できる

**ビジネスでの活用例:**
```
「@proposal.md この提案書の論理構成を評価して。弱い部分を指摘して」
「@meeting-notes.md この議事録からアクションアイテムを抽出して」
「@quarterly-report.xlsx のデータを分析して、傾向をまとめて」
```

### Inline Edit（Cmd+K）— テキストの一部を直させる

**何ができるか**: 選択したテキストに対して、自然言語で修正指示を出す。

**使い方:**
1. テキストを選択（選択なしならカーソル位置に新規生成）
2. `Cmd+K` を押す
3. 指示を入力（例: 「もっと簡潔にして」「敬語に直して」）
4. 提案を確認し、Accept/Reject

**ビジネスでの活用例:**
- メールの文面を丁寧な表現に直す
- 報告書の要約を短くする
- 箇条書きを文章に展開する

### Agent Mode（Cmd+I）— 大きな作業を丸投げする

**何ができるか**: 複数ファイルにまたがる大きなタスクを AI に任せる。計画→実行を自律的に行う。

**使い方:**
1. `Cmd+I` で Composer を開く
2. Agent モードを選択
3. タスクを記述
4. AI が計画を立て、ファイルを作成・編集する

**ビジネスでの活用例:**
```
「プロジェクト概要書のテンプレートを作成して。目的・背景・スケジュール・リスクの章立てで」
「先月の売上データから月次レポートのドラフトを作って」
```

### Tab 補完 — 書いている途中で AI が先を予測する

テキストを書いている最中に、AI が次に書くべき内容を予測して提案する。`Tab` で採用、`Esc` で却下。

コードだけでなく、文章の続きも予測する。

## 1-2. Claude Code の基本操作

### 起動と終了

1. 作業したいフォルダを開く（例: 書類 > project-x）
2. そのフォルダでターミナルを開く
   - **Mac**: Finder でフォルダを右クリック →「フォルダに新規ターミナル」
   - **Windows**: フォルダ内で Shift + 右クリック →「ここで PowerShell を開く」
3. `claude` と入力して Enter キーを押す
4. 終了するには `/exit` と入力するか、`Ctrl+C` を押す

### 自然言語で指示する

Claude Code では普通の言葉でリクエストする。特別なコマンドは不要。

**「調べて」の例:**
```
> このディレクトリのファイル構成を説明して
> report.md の内容を要約して
> data/ フォルダの CSV ファイルを分析して傾向を教えて
```

**「書いて」の例:**
```
> 競合分析レポートのテンプレートを作って
> meeting-notes.md の議事録からアクションアイテム一覧を作成して action-items.md に保存して
> このプロジェクトの README を作成して
```

**「整理して」の例:**
```
> docs/ フォルダ内のファイルをテーマ別に分類して一覧を作って
> 過去3ヶ月の議事録から決定事項だけを抽出してまとめて
> この長文レポートを要点3つに絞って要約して
```

### 承認フロー

Claude Code はファイルの作成・編集やコマンド実行の前に承認を求める（デフォルト設定）。

```
Claude wants to create action-items.md
[Allow] [Deny] [Allow All]
```

最初は 1 つずつ確認しながら進めるのがおすすめ。慣れたら Phase 5 で自動化する。

## 1-3. AI への効果的な指示の出し方（基礎）

### 悪い指示と良い指示

| 悪い例 | 良い例 | なぜ良いか |
|--------|--------|-----------|
| 「レポートを書いて」 | 「先月の売上データをもとに、経営会議向けの月次レポートを A4 1枚で作って」 | 目的・読者・分量が明確 |
| 「これを直して」 | 「この文章をクライアント向けの丁寧な表現に直して。専門用語は避けて」 | 方向性と制約が明確 |
| 「まとめて」 | 「この議事録から、誰が・いつまでに・何をするかのアクションアイテムを抽出して」 | 出力の形式が明確 |

### 指示の基本構造

```
[何を] + [誰のために / 何の目的で] + [どんな形式で]
```

**例:**
```
売上データの分析レポートを作成して。
経営会議で使用するため、A4 1枚に収まる分量で。
グラフ用のデータも併記して。
```

### `@` メンション — AI に参照すべきファイルを教える（Cursor）

Cursor では `@` を使って「これを見て作業して」と指定できる:

- `@filename` — 特定のファイルを参照
- `@folder` — フォルダ全体を参照
- `@web` — Web 検索結果を参照
- `@docs` — ドキュメントを参照

```
@sales-data.csv のデータをもとに @report-template.md の形式で月次レポートを作って
```

## 1-4. 実践: 最初の成功体験

### 演習 1: Cursor で文書を改善する

1. 自分が書いたメールや報告書を Cursor で開く（手元にない場合は、Claude Code に「ビジネスメールのサンプルを 1 通作って」と依頼してから開く）
2. テキストを選択し、`Cmd+K` で「もっと簡潔にして」と指示
3. AI の提案と元の文章を比較する

### 演習 2: Claude Code に調査・整理を任せる

1. ドキュメントが複数あるフォルダで Claude Code を起動
2. 「このフォルダのファイルを読んで、内容を一覧表にまとめて」とリクエスト
3. AI が自律的にファイルを読み取り、一覧を作成することを確認

### 演習 3: 議事録からアクションアイテムを抽出する

1. 議事録ファイルを用意する（なければサンプルを AI に作らせる）
2. Claude Code に「この議事録から、担当者・期限・タスクのアクションアイテム一覧を作って」とリクエスト
3. 結果をファイルとして保存できることを確認
