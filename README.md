# Cursor x Claude Code — Second Brain 完全ガイド

## 研修のゴール

この研修は、**AI を実務で活用するためのインフラを構築する**ことを目的としています。

### なぜインフラが必要か

Gemini や ChatGPT、NotebookLM はすでに多くの方が利用されています。ただし、これらのツールはチャット欄に貼り付けたテキストしか参照できず、作業結果は自分でコピーして貼り付ける必要があります。ブラウザを閉じると文脈がリセットされるため、毎回ゼロから説明し直すことになります。

Cursor × Claude Code は、PC 上のファイルに直接アクセスし、ファイル編集・コマンド実行まで AI が完結させます。判断基準や業務知識はローカルに永続保存され、セッションをまたいで引き継がれます。

### この研修を終えると何が変わるか

| | これまで（Gemini / NotebookLM 等） | この研修後（ローカル環境構築済み） |
|---|---|---|
| **AI の情報源** | チャット欄に貼り付けたテキストのみ | PC 上のファイル・フォルダに直接アクセス |
| **作業の実行** | 回答をコピーして自分で貼り付ける | AI がファイル編集・コマンド実行まで完結させる |
| **文脈の保持** | ブラウザを閉じるとリセット | 判断基準・業務知識がローカルに永続保存される |
| **アウトプット** | 汎用的な回答 | 自社・自分の実ファイルに基づく即使えるアウトプット |
| **セッション間の継続性** | 毎回ゼロから説明し直す | AI が前回の決定・経緯を引き継いで動く |

### この研修のゴール

1. **環境を構築する** — Cursor × Claude Code をインストールし、AI に実際に仕事を任せられる状態にします
2. **各領域の活用基盤を作る** — 営業・マーケ・開発・経営企画など、どの領域でも応用できる型を身につけます

## ゴール定義

**「Second Brain として使いこなしている」状態とは何か：**

> AI が自分の思考・判断基準・業務知識を理解し、情報収集・整理・分析・文書作成を自律的に遂行できる状態。
> 人間は**認知負荷の高い作業（調査・整理・下書き）を AI に委譲**し、自身のリソースを**判断・意思決定・人間関係**に集中させています。

### 測定指標

| 指標 | 使えていない状態 | Second Brain 化された状態 |
|------|-----------------|-------------------------|
| 認知負荷 | すべて自分の頭で処理する | 定型思考は AI に委譲し、判断だけ行う |
| コンテキスト供給 | 毎回背景から説明する | AI が自分の業務・判断基準・過去の決定を知っている |
| 情報処理速度 | 1つずつ順番に調べる | AI が並列に調査・分析し、要点だけ受け取る |
| アウトプット品質 | ゼロから自分で書く | AI の下書きを編集するだけで済む |
| 思考の連続性 | セッション間で文脈が途切れる | AI が過去の文脈を記憶し、積み上がる |

## 基本原理

```
AI のアウトプット = 推論の量 × 推論の精度
```

- **推論の量** = 早く・長く・多く動かす（速度 × 持続時間 × 並列度）
- **推論の精度** = 適切な input を供給する（preset + prompt）

精度（preset）が不十分な状態では、推論量を増やしても汎用的な回答しか得られません。まず preset を整備し、その後に量を最大化するという順序が重要です。

**preset の構成要素：**

| 要素 | 説明 | 何を入れるか |
|------|------|-------------|
| **Data** | 業務に関するファイル・ドキュメント | プロジェクト資料、議事録、仕様書 |
| **Rules** | 判断基準・制約・アウトプット形式 | 意思決定ポリシー、文書フォーマット、業界制約 |
| **Skills** | 再利用可能なアクション定義 | リサーチ、要約、比較分析、提案書作成 |
| **Memory** | 過去の学習・判断履歴の蓄積 | プロジェクト経緯、過去の意思決定とその理由 |

## フェーズ構成

```
Phase 0: Setup          ── 道具を揃える
Phase 1: Basic I/O      ── AI に調べさせる・書かせる・整理させる
Phase 2: Context Supply  ── 自分の「頭の中」を AI に渡す
Phase 3: Expansion       ── AI の知覚範囲を広げる
Phase 4: Workflow Design ── 業務タスクごとの AI 活用パターンを確立する
Phase 5: Autonomous      ── AI が先回りして動く仕組みを作る
```

### Phase 0: Setup（セットアップ）

**到達状態**: Cursor（エディタ）と Claude Code がインストールされ、基本的な動作確認が完了している

- Cursor のインストール（エディタとして使用）
- Claude Code CLI のインストールと認証
- 動作確認

→ [Phase 0: Setup](./phases/phase0-setup.md)

### Phase 1: Basic I/O（基本操作）

**到達状態**: AI に「調べて」「書いて」「整理して」と指示し、結果を受け取れる

- Claude Code: 自然言語による指示、ファイル操作
- 「AI に仕事をさせる」最初の成功体験

→ [Phase 1: Basic I/O](./phases/phase1-basic-io.md)

### Phase 2: Context Supply（文脈供給）

**到達状態**: AI が「自分の仕事の進め方」を理解している。毎回説明しなくても、自分好みのアウトプットが出る

- CLAUDE.md に業務知識・判断基準を記述する
- Rules にアウトプット形式・制約を設定する
- 「何を preset に書くべきか」の判断基準

→ [Phase 2: Context Supply](./phases/phase2-context-supply.md)

### Phase 3: Expansion（能力拡張）

**到達状態**: AI が外部の情報源やツールと接続され、定型的な業務アクションを自動化できる

- Skills: 再利用可能な業務アクション（リサーチ、要約、提案書作成等）
- MCP: 外部サービスとの接続（GitHub, Slack, DB, Web 等）
- Memory: 過去の判断・学習の蓄積
- Hooks: イベント駆動の自動処理

→ [Phase 3: Expansion](./phases/phase3-expansion.md)

### Phase 4: Workflow Design（ワークフロー設計）

**到達状態**: 業務タスクの種類に応じて、Claude Code を最適に活用できる

- ビジネスタスクの分類と Claude Code の活用パターン
- 典型的なワークフローパターン（調査、文書作成、意思決定支援）
- 応用: ソフトウェア開発での活用
- チームでの運用

→ [Phase 4: Workflow Design](./phases/phase4-workflow-design.md)

### Phase 5: Autonomous（自律駆動）

**到達状態**: AI が先回りして情報を整理し、人間は判断と意思決定だけに集中できる

- 自律実行の設定と安全装置
- バックグラウンドでの並列処理
- 継続的な改善サイクル

→ [Phase 5: Autonomous](./phases/phase5-autonomous.md)

### Phase と測定指標の対応

| Phase | 主に改善される指標 |
|-------|------------------|
| Phase 0-1 | 認知負荷（AI に作業を委譲できるようになる） |
| Phase 2 | コンテキスト供給、アウトプット品質（文脈供給により精度向上） |
| Phase 3 | アウトプット品質（能力拡張）、思考の連続性（Memory 導入） |
| Phase 4 | 情報処理速度（タスクに応じた最適な AI 活用で高速化） |
| Phase 5 | 情報処理速度（並列化）、思考の連続性（自律的に蓄積） |

## 学習の進め方

1. **Phase 0-1 は必ず順番に進める**（前提条件が積み上がるため）
2. **Phase 2-3 は必ず完了させる**（Phase 4-5 の前提条件。ここが Second Brain の核心）
3. **Phase 4 は Phase 2-3 の知識を前提とする**（文脈供給と能力拡張の上に成り立つ）
4. **Phase 5 は上級者向け**（Phase 0-4 が安定してから取り組む）

```
[Phase 0] → [Phase 1] → [Phase 2] → [Phase 3] → [Phase 4] → [Phase 5]
  道具を      調べさせる   頭の中を     知覚を       業務に       先回りして
  揃える      書かせる     渡す         広げる       組み込む     動かす

  ←── 精度の基盤を築く ──→ ←── 量を最大化する ──→
```
